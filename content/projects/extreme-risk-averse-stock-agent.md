## 项目定位

这是一个部署在 Cherry Studio 中的 **A 股辅助助手**，聚焦于极端风险厌恶型选股策略的执行与辅助决策。Agent 围绕"先避风险、再谈收益"的核心原则设计，以确定性优先、强止损风控为纲领，通过 PostgreSQL 数据库、多策略选股体系和定时任务系统，实现对 A 股日线数据的分析、评分与信号输出。

## 核心能力

### 📊 数据管理

| 能力 | 说明 |
|------|------|
| **PostgreSQL 数据库操作** | 直接访问本地 `my-postgres` 容器中的 `stock` 库，执行查询、更新与维护 |
| **双表架构** | 主表 `a_share_daily`（日线归档）+ 临时表 `a_share_daily_today`（盘中快照）无缝衔接 |
| **周 / 月 K 线** | 聚合视图与增量同步 |
| **数据源对接** | 小石金融 API（实时行情、新闻、历史数据）、Tushare（补数备选） |

### 📈 选股策略体系

Agent 围绕三道防线构建选股策略，环环相扣：

**1. 波段缩量回踩 · 双轴买入时机评分（`analyze_wave_buy.py`）**

核心决策工具，评估个股在缩量回踩结构下的买入时机安全性，包含：
- **买入分（1~100）**——当前位置的介入适宜度
- **回避分（0~100）**——当前位置需要规避的风险程度

支持批量运行、历史回测与适配性分析。

**2. SQL 策略组（三策略协同）**

| 策略 | 逻辑 |
|------|------|
| 缩量回踩低位 | 识别缩量回踩至支撑位的个股，筛选空方衰竭信号 |
| 冲高回落低吸 | 捕捉冲高后缩量回落的承接机会 |
| 单日急跌缩量 | 筛选单日大幅下跌但量能急剧萎缩的"空头力竭"信号 |

**3. 盘后回测**

- 无未来函数，可回溯历史信号质量
- 验证策略在不同市场环境下的真实表现

### 🤖 自动化任务

通过 **Cherry Studio Cron** 定时任务系统驱动：

| 时间 | 任务 |
|------|------|
| 盘中 14:30 | 快照 + 选股 |
| 15:05 | 收盘定格 |
| 每日 05:00 | 历史归档 |
| 每周三 / 五 | 基础信息更新 |

**`daily_auto_task.py`**：自动执行"三策略 → 合并 → 双轴评分 → 生成量化报告"的完整链路。

### 🔍 信息检索

- **小石语义新闻搜索**：可查询特定股票 / 行业的最新公告与新闻事件
- **网页搜索**：获取实时市场资讯

### 💾 智能记忆

Agent 具备持久化记忆能力，自动记录项目配置、技术决策与用户偏好，在后续会话中保持上下文一致。

## 风险控制原则

本 Agent 的设计围绕"极端风险厌恶"展开：

- 不追逐追涨信号，只捕捉回调确认后的低位机会；
- 双轴评分中的"回避分"优先于"买入分"，高回避分信号直接过滤；
- 盘中快照仅作观察，收盘后再做确认，避免盘中情绪干扰；
- 所有策略经盘后回测验证，无未来函数，历史表现可追溯审计。
